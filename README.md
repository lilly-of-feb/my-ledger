# 나만의 가계부 PWA

안드로이드 크롬에서 홈 화면에 설치할 수 있는 개인용 가계부입니다.

## 기능
- 지출/수입 버튼식 등록, 수정, 삭제
- 월별 수입·지출 합계와 예산 잔액
- 카테고리별 지출 통계
- 월 예산 설정 및 초과 표시
- 고정 지출 등록 및 월별 거래 자동 생성
- 거래 저장/수정/삭제 후 내부 자동 백업(최근 3개 버전)
- 거래 내역 급감 감지 시 자동 백업 중단 및 기존 백업 보존
- 복원 전 현재 데이터 별도 보관
- JSON 파일 백업 버튼과 7일 경과 알림, CSV 내역 내보내기
- 서비스 워커 캐시를 통한 오프라인 앱 셸 제공

## 데이터와 개인정보
거래 데이터는 브라우저의 `localStorage`에 저장됩니다. 서버로 거래 내역을 전송하지 않습니다. 내부 자동 백업은 같은 브라우저 저장공간에 최근 3개 버전으로 보관합니다. 거래 저장/수정/삭제 때 생성되며 앱 실행 때는 새 백업을 만들지 않습니다. 거래 내역이 갑자기 비거나 크게 줄어들면 자동 백업을 건너뛰어 기존 백업을 보호합니다. 브라우저 데이터 삭제나 사이트 저장공간 초기화 시 내부 자동 백업도 함께 사라질 수 있으므로, JSON 백업 버튼으로 7일에 한 번 이상 파일을 휴대폰의 별도 위치에 보관하세요. 같은 휴대폰이라도 브라우저/도메인이 바뀌면 저장공간은 별개입니다.

## 무료 배포: GitHub Pages
1. GitHub에서 새 저장소(repository)를 만듭니다.
2. 이 폴더의 파일 5개(`index.html`, `app.js`, `manifest.webmanifest`, `sw.js`, `icon.svg`)와 README를 저장소 최상위에 올립니다.
3. 저장소 Settings → Pages → Build and deployment에서 `Deploy from a branch`를 선택합니다.
4. Branch를 `main`, 폴더를 `/ (root)`로 선택하고 Save합니다.
5. 배포가 끝나면 표시되는 `https://계정.github.io/저장소명/` 주소를 안드로이드 Chrome으로 엽니다.
6. Chrome 메뉴(⋮) → `앱 설치` 또는 `홈 화면에 추가`를 선택합니다. 메뉴 문구는 기기/Chrome 버전에 따라 다를 수 있습니다.

GitHub Pages는 정적 파일 호스팅입니다. 이 앱은 별도 서버나 서버 DB를 사용하지 않습니다. 공개 저장소에 올려도 거래 데이터는 저장소에 업로드되지 않지만, 앱 소스는 공개됩니다. 소스 공개가 싫다면 비공개 저장소의 Pages 이용 가능 여부/요금 조건을 확인하거나 다른 무료 정적 호스팅을 선택하세요.

## 테스트
- HTTPS로 배포된 주소에서 실행해야 설치 및 서비스 워커 기능이 정상 작동합니다. `localhost`는 개발 테스트 예외입니다.
- 첫 접속은 온라인이어야 합니다. 한 번 앱 셸이 캐시되면 이후 오프라인에서도 화면을 열 수 있습니다.
- 오프라인 상태에서 앱을 새로 설치하거나 업데이트할 수는 없습니다.
- 이 버전은 Android Chrome 기준입니다. 은행 알림 읽기, 클라우드 동기화, 다중 기기 동기화는 구현하지 않았습니다.

## 참고
예산 초과는 앱을 열어 거래를 계산할 때 화면에 표시됩니다. 앱이 완전히 종료된 상태에서 시스템 알림을 보내는 기능은 포함하지 않습니다. 고정 지출은 앱을 실행할 때 결제일이 지난 항목을 해당 월 거래에 한 번 추가합니다.

## 보안 설계 참고
- 앱 코드에는 외부 분석/광고 SDK, 외부 스크립트, 은행 로그인/계정 연동이 없습니다.
- 거래 데이터는 브라우저 localStorage에만 기록합니다. 앱 코드에서 거래 데이터를 외부 서버로 전송하는 기능은 없습니다.
- Content Security Policy로 외부 스크립트 및 외부 연결을 기본 차단합니다.
- JSON 복원 시 필드와 값의 형식을 검증합니다. 신뢰할 수 없는 백업 파일은 복원하지 마세요.
- localStorage는 암호화 저장소가 아닙니다. 기기를 잠금 해제할 수 있는 사람이나 같은 출처에서 실행되는 악성 스크립트/브라우저 확장 프로그램은 데이터에 접근할 수 있습니다.
- GitHub Pages 저장소의 소스 코드 공개 여부와 거래 데이터 저장 위치는 별개입니다. 공개 저장소에는 앱 코드만 올라가며 거래 내역은 업로드되지 않습니다.


## 이번 개선 버전
- 지출/수입 카테고리와 결제수단을 앱의 '항목 관리'에서 추가·수정·삭제·순서 변경할 수 있습니다.
- 항목 이름/아이콘 변경은 기존 거래와 고정 지출에도 반영됩니다.
- 사용 중인 항목 삭제 시 다른 항목으로 거래를 이동해 보존합니다.
- 지출 등록에서만 결제수단을 선택하며, 수입은 결제수단을 사용하지 않습니다.
- CSV 열 순서: 날짜, 유형, 카테고리, 결제수단, 내용, 금액. 수입의 결제수단은 '-'로 표시합니다.
- JSON 백업에는 사용자 정의 항목 설정도 포함됩니다.
- 기존 버전의 카테고리 데이터를 새 기본 분류로 이전합니다.


## 월간 고정지출
- 고정지출 템플릿은 인앱에서 추가·수정·삭제할 수 있습니다.
- 항목마다 금액, 매월 결제일, 지출 카테고리, 결제수단을 저장합니다.
- 월간 고정지출 탭에서 선택된 월의 항목을 한 번에 가져옵니다.
- 결제일이 해당 월의 거래 날짜로 지정되며, 말일보다 큰 결제일은 해당 월 말일로 조정됩니다.
- 가져오기는 사용자가 직접 실행해야 하며 앱 실행만으로 거래가 자동 생성되지 않습니다.
- 같은 항목은 같은 월에 중복 가져오지 않습니다. 가져온 거래를 직접 삭제하면 다시 가져올 수 있습니다.
- 첫 실행 샘플 항목: 통신요금 19,800원 / 매월 21일 / 주거·통신 / 현금·이체.
- 기본 결제수단의 '현금' 명칭은 '현금·이체'로 변경되었습니다.
