# 나만의 가계부 PWA

안드로이드 크롬에서 설치해 사용할 수 있는 개인용 가계부입니다. 거래 데이터는 브라우저의 localStorage에 저장되며 서버로 전송되지 않습니다.

## 배포 및 업데이트
1. GitHub 저장소 `my-ledger`의 Code 화면에서 Add file → Upload files를 선택합니다.
2. 이 폴더 안의 파일 6개를 저장소 루트에 업로드하고 기존 파일은 덮어씁니다.
3. Commit changes를 누릅니다. GitHub Pages가 자동으로 다시 배포됩니다.
4. 설치된 앱을 완전히 닫았다가 인터넷 연결 상태에서 다시 열어 새 버전이 적용되는지 확인합니다.

## 데이터 보관
- 거래 내역은 해당 휴대폰/브라우저의 localStorage에 저장됩니다.
- JSON 백업은 별도 파일로 내려받아 보관하고, 복원 메뉴에서 선택할 수 있습니다.
- 앱 파일을 업데이트해도 기존 브라우저 저장 데이터는 유지됩니다. 단, 브라우저의 사이트 데이터 삭제나 앱 데이터 초기화는 피해주세요.

## 주요 기능
- 수입·지출 등록, 수정, 삭제 및 월별 내역
- 생활비 예산: 외식비부터 경조사까지 기본 지출 카테고리 8개의 합계로 집계
- 지출분류 및 수입분류 통계
- 지출 카테고리·수입 카테고리·결제수단 관리
- 월간 고정지출 템플릿과 선택 월 일괄 가져오기
- JSON 백업·복원 및 CSV 내보내기
